APRENDER DESDE LO BÁSICO

La tecnología detrás de cada conexión

Consultar el correo, participar en una videollamada o ingresar a una plataforma educativa son actividades cotidianas. En estas tres entradas exploramos los conceptos que permiten comprender cómo funcionan estos servicios.

ENTRADA 01 · CONCEPTOS BÁSICOS

¿Qué es una aplicación en red?

Publicado el 2 de noviembre de 2026

Una aplicación en red es un programa que utiliza una red de comunicaciones para intercambiar información con otros equipos o servicios. Esta comunicación puede realizarse a través de Internet o dentro de una red local, como la de una institución educativa o una empresa.

Algunos ejemplos son el correo electrónico, las plataformas educativas y las aplicaciones de mensajería. Aunque sus funciones son diferentes, todas necesitan enviar y recibir datos para ofrecer sus servicios.

Un ejemplo cotidiano

Cuando ingreso a una plataforma educativa para consultar una actividad, mi navegador solicita información al servidor. Este procesa la solicitud y devuelve el contenido que aparece en la pantalla.

Una ventaja de estas aplicaciones es que permiten compartir recursos y acceder a información desde distintos lugares. Sin embargo, sus funciones en línea dependen de la conexión y de la disponibilidad del servicio.

ENTRADA 02 · COMUNICACIÓN

¿Cómo funciona el modelo cliente-servidor?

Publicado el 2 de noviembre de 2026

El modelo cliente-servidor organiza la comunicación entre dos participantes. El cliente solicita un recurso o servicio y el servidor recibe la solicitud, la procesa y envía una respuesta. Un navegador web puede actuar como cliente, mientras que un servidor web proporciona páginas y archivos.

El recorrido de una solicitud

  1. El usuario abre una dirección web en el navegador.
  2. El navegador envía una solicitud al servidor.
  3. El servidor procesa la petición y devuelve una respuesta.
  4. El navegador interpreta el contenido y muestra la página.

En la Web, este intercambio utiliza HTTP o su versión protegida mediante TLS, conocida como HTTPS. HTTPS cifra los datos durante su transmisión, lo que ayuda a proteger la información intercambiada.

Por ejemplo, al consultar un catálogo de productos, el navegador solicita los datos y el servidor responde con la información disponible. Si el servicio deja de funcionar, el cliente no podrá obtener nuevas respuestas hasta que se restablezca.

ENTRADA 03 · DESARROLLO WEB

HTML y CSS: estructura y presentación de una página

Publicado el 2 de noviembre de 2026

HTML es un lenguaje de marcado que permite organizar el contenido de una página web. Mediante sus etiquetas se definen títulos, párrafos, imágenes, enlaces y secciones. Esta estructura ayuda a identificar la función de cada elemento dentro del documento.

CSS es un lenguaje de estilos que define la presentación de ese contenido. Permite establecer colores, tamaños de letra, márgenes y distribución de los elementos. También ayuda a adaptar el diseño a diferentes tamaños de pantalla.

¿Cómo se complementan?

En este blog, HTML organiza el encabezado, el menú y las entradas. La hoja de estilos CSS define su apariencia. Mantener el contenido y los estilos en archivos separados facilita modificar el diseño sin tener que reescribir los textos.

Los enlaces del menú utilizan identificadores de las secciones para desplazarse dentro de la misma página. Esta navegación funciona con HTML y no necesita JavaScript. Un blog estático puede publicarse sin una base de datos ni código de servidor que genere sus páginas.
